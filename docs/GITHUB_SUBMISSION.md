## Repository Description

Autonomous AI social media engine and creator digital twin for Android, built with Kotlin, Jetpack Compose, Room, Hilt, Gemini, OpenRouter, Qdrant, Firecrawl, and YouTube Data API.

## Repository Short Tagline

The creator sleeps. BrandForge works.

## GitHub About Section

BrandForge is a mobile-first AI creator operating system. It learns Brand DNA, retrieves Creator Memory, scores trends, generates content, detects leads, analyzes competitors, and powers a Digital Twin Chat.

## First Release Notes

### Highlights

- Retro cyber command-center Android UI.
- Brand DNA onboarding and persistence.
- Creator Memory with Room and Qdrant.
- Trend Intelligence from Firecrawl and YouTube Data API.
- Opportunity scoring with brand fit, freshness, and velocity.
- Content generation for Reel Scripts, Instagram Carousels, and X Threads.
- Digital Twin Chat with contextual citations.
- Lead Detection using Gemini Flash Lite.
- Competitor Intelligence with gap analysis.
- Voice command support using Android SpeechRecognizer.

### Known Limits

- No publishing workflow.
- No CRM integration.
- No WhatsApp integration.
- No social login or account linking.
- No overnight automation in this release.
- Real API keys are required for live data and model calls.
